## обо мне

Пишу на Python четвёртый с половиной год. Начинал с сайтов на HTML и CSS,
потом делал игры на Unity, сейчас ушёл в backend.

Был на трёх хакатонах — там хорошо видно, что ты правда умеешь, а что просто помнишь.

Стараюсь не просто заставить код работать, а понять, почему он работает.
Иногда возвращаюсь к старым проектам и переписываю их заново — по-другому прогресс не увидеть.
Если технология незнакомая, это не повод её обходить.
