## about

Python — 4.5 года. Начинал с сайтов на HTML + CSS и игр на Unity, сейчас двигаюсь
в backend. За плечами 3 хакатона: там быстро выясняется, что ты действительно понимаешь,
а что просто помнишь.

Не гонюсь за «уметь». Гонюсь за «понимать, почему это работает именно так».
Регулярно возвращаюсь к старым проектам и переписываю — прогресс видно только так.
Незнакомая технология — не стоп-сигнал, а повод разобраться.

<br/>

- **сейчас изучаю** — backend, архитектуру приложений, работу с БД
- **практикую** — pet-проекты, чтобы не терять руку
- **цель** — уверенно чувствовать себя в реальной разработке, а не только в теории
